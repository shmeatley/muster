Config

Validates and normalizes a [MatchmakerConfig] into the frozen settings table every other module reads.

resolve returns (settings, problem) rather than throwing, so the validation rules are directly testable and so the error surfaces at the caller's Muster.new(...) line rather than somewhere inside this module. Matchmaker turns a non-nil problem into an error(problem, 2).

Functions​

normalizePartition​

</>
Config.normalizePartition(value: string) → string

Folds a partition key down to something a MemoryStore name can hold. Short keys pass through unchanged so lane names stay readable in logs; anything longer or containing awkward characters is hashed.
