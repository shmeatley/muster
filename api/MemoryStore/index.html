MemoryStore

The production [Store]: Roblox MemoryStore hash maps and sorted maps behind a RequestExecutor.

A Matchmaker builds one automatically. Construct it directly to share a single executor across several queues, which pools their health tracking and circuit breakers: 

local executor = Muster.internal.RequestExecutor.new({ logger = log })
local store = Muster.stores.MemoryStore.new(executor)

local ranked = Muster.new({ name = "ranked", size = 8, store = store })
local casual = Muster.new({ name = "casual", size = 8, store = store })

Reads the oldest count entries. Sort keys are queue timestamps, so ascending order is first-come-first-served.

NOTE

MemoryStore caps a range read at 200 items. A lane holding more is matched only from its oldest 200, which biases the rating window. LaneScaler treats a full batch as the signal to add lanes.
