Muster

Cross-server matchmaking for Roblox.

Players and parties go into a queue; Muster handles the distributed part — sharded queue lanes, worker election, skill-windowed grouping, and delivery of the result to every server holding a matched player. It stops at the match envelope: it does not teleport, does not reserve servers, and does not compute or store ratings. Those are yours, and finalize is where they attach. 

local Muster = require(ReplicatedStorage.Packages.Muster)

local duels = Muster.new({ name = "duels", size = 2 })

duels.matched:connect(function(match)
	print(`{match.size} players matched as {match.matchId}`)
end)

duels:enqueue(player.UserId)

See Matchmaker for the queue itself, Party for cross-server parties, and Result for the error convention.
