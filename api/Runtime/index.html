Runtime

This item is only intended to be used by the module's authors. Private

The only module in Muster that touches a Roblox global. Everything else receives what it needs through configuration, which is what lets the whole engine run headlessly under Lune against fakes.

Each global is read through an any-typed local so the same source typechecks under Roblox (where game exists) and runs under Lune (where it resolves to nil).
