Signal

A minimal event, used for Matchmaker's matched, aborted, queued and cancelled. Muster ships its own so the package has no runtime dependencies.

Handlers fire synchronously, in connection order, on the thread that raised the event. A handler that throws is reported and skipped; the remaining handlers still run. Disconnecting from inside a handler is safe, because each fire iterates a snapshot of the handler list. 

local connection = queue.matched:connect(function(match)
	print(match.matchId)
end)

connection:disconnect()
