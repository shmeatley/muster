Result

Muster splits failures by cause: if it's your bug, it throws; if it's the network's fault, it's a Result.

Bad configuration and bad arguments raise an error at level 2, so the traceback points at your call. Anything that depends on MemoryStore being reachable — enqueueing, cancelling, party mutations — returns a Result instead, because those genuinely fail in production and a correct program has to branch on them. 

local result = queue:enqueue(player.UserId, { rating = 1200 })
if not result.ok then
	if result.error.code == "AlreadyQueued" then
		return "You're already in a queue."
	end
	return if result.error.retryable then "Try again in a moment." else "Couldn't queue."
end
print("queued as", result.value.id)
