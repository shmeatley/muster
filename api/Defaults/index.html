Defaults

Every tunable in one table, with the reasoning attached. Anything here that is worth changing per game is exposed on [MatchmakerConfig]; the rest are protocol constants that all servers must agree on, and changing one means draining the queue first. 

print(Muster.Defaults.LEASE_DURATION) -- 15

Functions​

aggregate​

</>
Defaults.aggregate(ratings: {number}) → number

Party rating from its members' ratings: the mean pulled PARTY_RATING_MAX_BIAS of the way toward the highest member.

ratingWindow​

</>
Defaults.ratingWindow(
rating: any,
waitSeconds: number
) → number

How wide the rating window is after waiting waitSeconds. Linear growth from window at relax per second, uncapped once unbounded is reached.

scanDelay​

</>
Defaults.scanDelay(
candidateCount: number,
throttled: boolean
) → number

How long to wait before the next scan of a lane. Busy lanes are scanned aggressively; empty ones back off, and everything halves its rate when the store reports throttling.

batchSize​

</>
Defaults.batchSize(previousCount: number) → number

How many candidates to read on the next scan, sized from the previous one so a quiet queue does not pay for a large range read.
