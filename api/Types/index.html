Types

Every type Muster exposes. Has no runtime dependencies.

These are re-exported from the package root, so write Muster.MatchEnvelope rather than requiring this module directly.

Types​

Metadata​

</>
type Metadata = {[string]: any}

Caller-supplied data carried on a ticket.

Must survive a JSON round trip through MemoryStore: strings, numbers, booleans, and tables of those. Functions, Instances, cycles, and tables mixing array and dictionary keys are rejected at enqueue with InvalidMetadata. Limited to maxMetadataBytes (1024).

Member​

</>
interface Member {
userId: number
serverId: string--

JobId of the server that enqueued them; where their match is delivered.

rating: number?--

Present if and only if the queue is rated.

provisional: boolean?--

True when rating.default was substituted for a missing rating.

metadata: Metadata?
}

One player within a ticket or a match.

serverId is per-member rather than per-ticket because a party's members can be on different servers, and each is notified on their own.

MatchEnvelope​

</>
interface MatchEnvelope {
v: number--

Schema version.

matchId: string

Total players across all members.

A committed match, delivered to every server holding one of its members.

Generic over the finalizer's return type, so match.data.accessCode is typed and autocompletes.

Deduplicate on matchId. The same set of players may appear under a second matchId if a worker stalled and its work was repaired.

AbortReason​

</>
type AbortReason = "FinalizerError" | "FinalizerTimeout" | "FinalizerTooLarge" | "LeaseLost" | "StoreUnavailable" | "TicketStolen"

Why a match that had already claimed its tickets failed to commit. Its players return to the queue in every case.

Reason Cause
FinalizerError The hook threw.
FinalizerTimeout The hook did not return within finalizeTimeout.
FinalizerTooLarge The hook's return value failed validation or exceeded maxMatchDataBytes.
LeaseLost Another server took the lane while the hook was yielding.
StoreUnavailable MemoryStore rejected the commit.
TicketStolen A ticket was claimed by another match between selection and commit.

AbortContext​

</>
interface AbortContext {
matchId: string
queue: string
partition: string
members: {Member}
reason: AbortReason
message: string?--

The hook's error text, when reason is FinalizerError.

data: any?--

The hook's return value, if it produced one before the abort.

}

The argument to onAbort.

When data is present, the hook ran to completion and its side effects outlived a match that never formed.

Finalizer​

</>
type Finalizer = (context: MatchContext) → T

Runs once per matchId, on the server that formed the match, after its tickets are claimed and before it commits. Expected to yield.

The same set of players may be finalized again under a different matchId if this match aborts, so deduplicate on matchId.

Store​

</>
interface Store {}

The storage contract, implemented by Muster.stores.MemoryStore against Roblox MemoryStore and by Muster.stores.InMemory against tables.

Every method returns (success, value) and must not throw.

update must be a compare-and-set: the transform may be invoked more than once for a single call, and returning nil from it must abort the write.

MatcherPolicy​

</>
interface MatcherPolicy {
minSize: number
targetSize: number
maxSize: number
fallbackAfter: number--

Seconds before a below-target group is accepted.

compatible: (
anchor: Candidate,
candidate: Candidate,
waitSeconds: number
) → boolean
score: (
candidates: {Candidate},
indexes: {number}
) → (
number,
number
)
}

Everything Matcher knows about how to group candidates. Supply one through the matcher config field to replace the rating window with role composition, region affinity, or any other rule.

compatible decides whether a candidate may join an anchor's group.

score returns (primary, secondary), both minimized and compared in that order. The built-in policy uses rating spread, then total queue time.

RatingConfig​

</>
interface RatingConfig {
window: number?--

Starting rating tolerance. Default 200.

relax: number?--

Extra tolerance per second waited. Default 40.

maxWindow: number?--

Ceiling on the widened window. Default infinite.

unbounded: number?--

Seconds after which any rating matches. Default 60.

default: number?--

Substituted when a caller omits a rating. Default nil, which makes omission an error.

aggregate: (({number}) → number)?--

Party rating from member ratings. Default is a max-biased mean.

}

Supplying this table makes a queue rated. Omit it for an unrated queue, where tickets carry no rating and matching is oldest-first.

Rated and unrated is a per-queue property: a rated queue requires a rating for every player, and an unrated one rejects them.

SizeConfig​

</>
interface SizeConfig {
min: number
target: number?
max: number?
}

Match sizing. size = 6 is shorthand for all three being 6, and target defaults to max.

A group reaching target commits immediately. A smaller one waits fallbackAfter seconds, after which the largest group down to min is accepted.
